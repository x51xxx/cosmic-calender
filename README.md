## 📖 Що таке Космічний Календар?

Космічний календар — це метод візуалізації, запропонований Карлом Саганом, який дозволяє зрозуміти масштаби історії Всесвіту. Якщо уявити, що Великий вибух стався 1 січня о 00:00:00, то сьогодення — це 31 грудня о 23:59:59.

### Масштаб часу

- **1 рік** = 13,8 мільярдів років
- **1 місяць** ≈ 1,15 мільярдів років
- **1 день** ≈ 37,8 мільйонів років
- **1 година** ≈ 1,6 мільйона років
- **1 хвилина** ≈ 26 000 років
- **1 секунда** ≈ 438 років

### Ключові моменти

- **1 січня, 00:00:00** — Великий вибух
- **14 січня** — Найстарші гамма-спалахи
- **22 січня** — Перші галактики
- **16 березня** — Формування Чумацького Шляху
- **2 вересня** — Формування Сонячної системи
- **14 вересня** — Сліди біологічного життя
- **21 вересня** — Поява життя (прокаріоти)
- **30 вересня** — Фотосинтез
- **29 жовтня** — Оксигенація атмосфери
- **9 листопада** — Складні клітини (еукаріоти)
- **5 грудня** — Багатоклітинне життя
- **14 грудня** — Кембрійський вибух
- **24 грудня** — Пермське вимирання (90% видів)
- **25 грудня** — Динозаври
- **30 грудня, 06:24** — Вимирання динозаврів
- **31 грудня, 06:05** — Людиноподібні мавпи
- **31 грудня, 22:24** — Кам'яні інструменти
- **31 грудня, 23:44** — Приручення вогню
- **31 грудня, 23:52** — Анатомічно сучасна людина
- **31 грудня, 23:59:32** — Сільське господарство
- **31 грудня, 23:59:48** — Перша писемність
- **31 грудня, 23:59:54** — Будда, Конфуцій, Античність
- **31 грудня, 23:59:59** — Сучасність

**Вся історія людської цивілізації займає лише останні 28 секунд космічного року!**

## 🚀 Локальний запуск

### Простий спосіб (Python)

```bash
# Клонуйте репозиторій
git clone https://github.com/x51xxx/cosmic-calender.git
cd cosmic-calender

# Запустіть локальний сервер
python3 -m http.server 8000

# Відкрийте http://localhost:8000 у браузері
```

### Альтернативний спосіб (Node.js)

```bash
# Встановіть http-server глобально
npm install -g http-server

# Запустіть сервер
http-server

# Відкрийте http://localhost:8080 у браузері
```

### Або просто відкрийте файл

Просто відкрийте файл `index.html` у вашому браузері.
